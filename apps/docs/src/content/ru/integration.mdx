# Руководство по интеграции

Как показать это руководство внутри React-приложения так, как это делает планировщик: кнопка, которая открывает главы о
текущем экране в выдвижной панели, на языке и в теме приложения, с загрузкой оттуда, где задеплоено руководство. Каждый
фрагмент ниже — настоящий код из двух хостов в этом репозитории: планировщика (`apps/web`) и тестовой обвязки
(`apps/docs-harness`).

## Что вы получаете и чего это стоит хосту

- **Ничего до первого клика.** Рантайм федерации, манифест и код руководства загружаются при первом открытии панели.
  Первый бандл хоста не растёт.
- **Один React.** Руководство использует React хоста и не скачивает свой.
- **Никаких утечек.** Панель живёт в shadow root под одним элементом `<lc-docs>`: CSS хоста не проникает внутрь, CSS
  руководства не выходит наружу, клавиши, нажатые в руководстве, не запускают горячие клавиши хоста, а его ссылки
  никогда не меняют URL хоста. `destroy()` убирает всё это.
- **Хост решает**, какие будут язык и тема и на каком экране находится человек. Руководство отвечает типизированными
  событиями.
- **Запасной вариант.** Если руководство не удаётся загрузить, хост даёт ссылку на ту же страницу статического сайта.

Требования: React в пределах `^19.3.0` и способ передать браузеру URL во время выполнения.

## 1. Добавьте два пакета

В `@lc/docs-contract` лежат типы и хелперы, о которых договорились обе стороны; в `@lc/remote-host/docs` — React-хук, который
загружает remote. В этом репозитории это пакеты workspace:

```json file=apps/web/package.json at=main lines=18

```

```json file=apps/web/package.json at=main lines=24

```

В реестр они не опубликованы. Хосту вне этого репозитория пока пришлось бы скопировать их к себе (vendoring).

## 2. Сделайте адрес настройкой времени выполнения

Адрес руководства нельзя вшивать в сборку хоста, иначе каждый переезд руководства на новое место означал бы пересборку
хоста. Планировщик читает его на сервере, при каждом запросе:

```ts file=apps/web/src/server/docs.ts at=main

```

| Переменная        | Значение                                                                                                       | Если не задана                                                                                   |
| ----------------- | -------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| `DOCS_REMOTE_URL` | Файл `mf-manifest.json` remote, например `https://<owner>.github.io/learning-curve/remote/v1/mf-manifest.json` | В разработке: локальный статический сервер на порту 4310. В production: кнопки документации нет. |
| `DOCS_SITE_URL`   | Статический сайт — для запасной ссылки и «открыть в новой вкладке»                                             | На два уровня выше манифеста: там сайт и находится, когда их деплоят вместе                      |

Обвязка делает то же самое через query-параметры (`?remote=`, `?site=`, `?timeout=`), так что одну её сборку можно
направить на любой деплой.

## 3. Отрендерьте кнопку

`useDocsHost` возвращает статус, причину последней ошибки и `open` / `close`. Вот кнопка планировщика:

<Walkthrough>

```tsx file=apps/web/src/shell/DocsButton.tsx at=main

```

<WalkStep lines="9-15" title="Сопоставить экраны с фичами">

Id фичи называет слайс кода (`planner/pages/timeline`). Каталог руководства знает, какие главы построили каждый из них,
поэтому открытие по фиче показывает «Главы об этом экране».

</WalkStep>

<WalkStep lines="28-31" title="Текущий экран и язык">

Фичу определяет маршрут. Язык хоста передаётся, если он есть в руководстве, иначе передаётся русский.

</WalkStep>

<WalkStep lines="33-36" title="Хук">

`theme: 'inherit'` заставляет панель следовать цветовой схеме и дизайн-токенам хоста. Контекст может измениться в любой
момент; хук передаёт изменения в открытую панель.

</WalkStep>

<WalkStep lines="39-51" title="Запасной вариант">

Если загрузка не удалась, кнопка становится ссылкой на ту же цель на статическом сайте (её строит `docsPageUrl`) и
остаётся ссылкой до перезагрузки страницы.

</WalkStep>

<WalkStep lines="52-61" title="Открыть по клику">

`open` загружает всё при первом использовании. `aria-busy` сообщает вспомогательным технологиям, что кнопка занята, пока
идёт загрузка.

</WalkStep>

</Walkthrough>

## 4. Контекст

| Поле        | Тип                                  | Что делает                                                                                                                                                 |
| ----------- | ------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `locale`    | `'ru' \| 'en' \| 'es'`               | Язык панели. При его изменении открытая панель переходит на ту же страницу на новом языке.                                                                 |
| `theme`     | `'inherit' \| 'light' \| 'dark'`     | `inherit` следует `color-scheme` и CSS-переменным хоста; `light` и `dark` закрепляют тему.                                                                 |
| `tokens`    | `Partial<Record<DocsToken, string>>` | Необязательные CSS-значения для `bg`, `surface`, `surface-2`, `ink`, `muted`, `line`, `focus` — для хоста, у которого собственные токены называются иначе. |
| `featureId` | `FeatureId`                          | Слайс на экране. Стартовая страница панели перечисляет главы, которые его построили.                                                                       |
| `siteUrl`   | `string`                             | Статический сайт — для «открыть в новой вкладке» и для запасного варианта при ошибке внутри панели.                                                        |

Цель для `open` — это `{ chapterId }` для одной главы или `{ topicId }` для глав о фиче. Id типизированы контрактом, так
что опечатка не скомпилируется.

## 5. События

Шесть событий, у каждого типизированный payload. Обвязка пишет их все в лог:

```tsx file=apps/docs-harness/src/App.tsx at=main lines=45-62

```

| Событие                 | Payload                        | Когда                                                               |
| ----------------------- | ------------------------------ | ------------------------------------------------------------------- |
| `docs:ready`            | `{ version }`                  | Панель создана; версия контракта, которую реализует remote          |
| `docs:open`             | цель                           | Хост открыл панель                                                  |
| `docs:navigate`         | цель                           | Человек перешёл на другую страницу внутри панели                    |
| `docs:close`            | `{ reason: 'user' \| 'host' }` | Панель закрылась: `Escape` или кнопка закрытия либо `close()` хоста |
| `docs:language-changed` | `{ locale }`                   | Хост изменил `locale`                                               |
| `docs:error`            | `{ feature, message }`         | Страница руководства не отрендерилась; панель предлагает повторить  |

Обработчики читаются в момент срабатывания события, так что передавать новый объект на каждом рендере — нормально.

## 6. Версии

Контракт следует semver, его changelog лежит в `packages/docs-contract/CHANGELOG.md`.

- **Минорные и патч-релизы** руководства каждый хост подхватывает при следующей загрузке. Делать ничего не нужно.
- **Мажорный** релиз деплоится в новую папку (`remote/v2/`) рядом со старой. Хост продолжает загружать `v1`, пока его не
  обновят: поднимите версию пакета контракта, исправьте то, на что укажет компилятор, направьте `DOCS_REMOTE_URL` на
  `v2`.

Хук отклоняет remote другой мажорной версии до запуска любого его кода и сообщает причину в `failure`:

| `failure`     | Значение                                     | Что проверить                                                                                                   |
| ------------- | -------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| `timeout`     | Нет ответа за `timeoutMs` (по умолчанию 8 с) | Что хостинг руководства работает; сеть                                                                          |
| `unavailable` | Не загрузился манифест, точка входа или чанк | URL; CORS на хостинге руководства; деплой, который заменил файлы, пока страница была открыта (перезагрузите её) |
| `shape`       | Модуль не экспортирует `createDocsHost`      | URL указывает на другой remote                                                                                  |
| `version`     | Remote реализует другую мажорную версию      | Направьте хост на подходящий `remote/vN/` или обновите хост                                                     |

Хук сбрасывает неудачную загрузку, поэтому повторный вызов `open` пробует снова. Обвязка ради этого оставляет свою
кнопку; планировщик вместо этого переключается на ссылку.

## 7. Задеплойте руководство

Руководство — это статические файлы: сайт в корне, remote в `remote/v1/`, стенд в `stand/`. Подойдёт любой статический
хостинг, который:

- отправляет `Access-Control-Allow-Origin` для файлов remote (хост импортирует их с другого origin);
- не кэширует `mf-manifest.json` надолго или позволяет хосту обойти кэш. Хук добавляет к URL манифеста меняющийся
  query-параметр. У всех остальных файлов в имени есть хеш содержимого, и их можно кэшировать навсегда.

Репозиторий деплоится на GitHub Pages, который отправляет `Access-Control-Allow-Origin: *` и `max-age=600` для каждого
файла. Сборка читает две переменные:

| Переменная    | Для чего                                                 | Пример                      |
| ------------- | -------------------------------------------------------- | --------------------------- |
| `DOCS_BASE`   | Путь, по которому отдаётся сайт                          | `/learning-curve/`          |
| `DOCS_ORIGIN` | Абсолютные URL в `hreflang`, canonical-ссылках и sitemap | `https://<owner>.github.io` |

Самому remote не нужна ни одна из них: URL его чанков вычисляются от того места, откуда загружен его манифест.

Если хост отправляет Content-Security-Policy, она должна разрешать origin руководства в `script-src` (точка входа и
чанки — это скрипты) и в `connect-src` (манифест загружается через fetch), а также Google Fonts
(`style-src https://fonts.googleapis.com`, `font-src https://fonts.gstatic.com`), если хост ещё не загружает шрифты
руководства. Ни один хост в этом репозитории политику не отправляет: список выведен из того, что загружает панель, и не
проверялся.

## 8. Проверьте

`apps/docs-harness` — минимальный хост с враждебным глобальным CSS, горячими клавишами на window и переключателями языка
и темы. Его тесты на Playwright загружают production-сборку руководства и проверяют то, что важно хосту: до клика ничего
не загружается, React не скачивается дважды, язык и тема следуют за хостом, ссылки переключают страницы только в панели,
стили и клавиши остаются на своей стороне, а когда remote недоступен, появляется запасной вариант.

## Решение проблем

| Симптом                                                            | Вероятная причина                                                                                                                                                    |
| ------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Кнопка сразу превращается в ссылку                                 | Загрузка не удалась: посмотрите `failure` из хука, затем вкладку Network в браузере                                                                                  |
| Ошибка CORS на `mf-manifest.json`                                  | Хостинг руководства не отправляет `Access-Control-Allow-Origin`                                                                                                      |
| Предупреждение React об общей версии                               | React хоста вне диапазона `^19.3.0`; remote всё равно использует копию хоста                                                                                         |
| Горячая клавиша хоста срабатывает, пока вы печатаете в руководстве | Хост слушает в фазе перехвата (`addEventListener(…, true)`), которая выполняется до того, как событие дойдёт до shadow root руководства, и остановить его там нельзя |
| Старые главы сразу после деплоя                                    | Кэш статического хостинга (десять минут на GitHub Pages); после этого перезагрузка покажет новую версию                                                              |
