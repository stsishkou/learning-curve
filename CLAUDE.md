# learning-curve — notes for coding agents

- Stack: TanStack Start (React 19, file routes in `src/routes`, server routes via `server.handlers`), Vite 8, Nitro, TypeScript strict, Tailwind CSS v4 (utility classes in components, tokens in `src/styles.css`).
- Source of truth for the schedule: `src/lib/plan/content.ts` + `src/lib/plan/schedule.ts`. `src/data/plan.json` is generated by `pnpm run plan`; never hand-edit it, regenerate. Manual changes made in the viewer live in `src/data/edits.json` (patches by event uid) and are applied by the same command; `src/lib/plan/store.ts` is the only code that writes either file.
- After changing content or rules: `pnpm run plan && pnpm run typecheck && pnpm run build`.
- Before finishing any change: `pnpm run check` (typecheck, Oxlint, Oxfmt check, translation check). Format with `pnpm run fmt`.
- Weekly study budget is 12 h; `pnpm run plan` warns when a week exceeds it. Gym and Saturday buffer do not count.
- Times are Europe/Minsk wall-clock strings; use helpers in `src/lib/plan/dates.ts`, never `new Date(localString)`. Locale-aware date and hour text comes from `src/lib/format.ts`.
- UI text is localized (ru base, en, es) with Paraglide JS: add every string to all three `messages/*.json` files and call it as `m.key()`; never hardcode UI text. Run `pnpm run check:i18n` after editing messages. `src/paraglide/` is generated, never edit it. Plan content stays Russian. Code and docs are English. Event titles: `<Course short name> — <Module / topic>`; descriptions: course URL, module URL, 1–3 line goal.
- `src/routeTree.gen.ts` is generated by the router plugin.
- Commits follow Conventional Commits; commitlint enforces it in a `commit-msg` hook.
