# learning-curve — notes for coding agents

- Nx + pnpm workspace. `apps/web` is a thin TanStack Start shell (React 19, file routes in `apps/web/src/routes`, server functions in `apps/web/src/server`, Vite 8, Nitro). `modules/*` are build-time microfrontends with Feature-Sliced layers inside. `packages/*` are shared: `plan-domain` (pure TS), `plan-data` (Node, JSON files), `i18n`, `ui`. Read `docs/architecture.md` before adding a file: it says where things go and what may import what.
- Dependency rules are enforced by lint (`.oxlintrc.json` overrides, `steiger.config.ts`). Modules never import each other, `@lc/plan-data`, `node:*` or server functions: the app passes data and callbacks in as props. Imports inside a package are relative; other packages are imported by name through their public entry.
- Packages are consumed as TypeScript source (no build step, `exports` point at `src`). Do not use a path alias inside `modules/*` or `packages/*`: the app type-checks their sources with its own tsconfig.
- Source of truth for the schedule: `packages/plan-domain/src/content.ts` + `schedule.ts`. `packages/plan-data/data/plan.json` is generated by `pnpm run plan`; never hand-edit it, regenerate. Manual changes made in the viewer live in `packages/plan-data/data/edits.json` (event patches by uid, renamed and added calendars, added events) and are applied by the same command. Every edit is a `PlanChange` handled by `applyChange` in `packages/plan-domain/src/changes.ts`: add a new kind of edit there, not as a new server function; `packages/plan-data/src/store.ts` is the only code that writes either file.
- After changing content or rules: `pnpm run plan && pnpm run check && pnpm run build`.
- Before finishing any change: `pnpm run check` (typecheck, Oxlint, Steiger, translation check, Oxfmt check). Format with `pnpm run fmt`. One project: `pnpm exec nx run @lc/planner:typecheck`.
- Weekly study budget is 12 h; `pnpm run plan` warns when a week exceeds it. Gym and Saturday buffer do not count.
- Times are Europe/Minsk wall-clock strings; use the date helpers exported by `@lc/plan-domain`, never `new Date(localString)`. Locale-aware date and hour text comes from `@lc/i18n/format`.
- UI text is localized (ru base, en, es) with Paraglide JS: add every string to all three `packages/i18n/messages/*.json` files and call it as `m.key()` (`import { m } from '@lc/i18n/messages'`); never hardcode UI text. Run `pnpm run check:i18n` after editing messages. `packages/i18n/src/paraglide/` is generated, never edit it. Plan content stays Russian. Code and docs are English. Event titles: `<Course short name> — <Module / topic>`; descriptions: course URL, module URL, 1–3 line goal.
- TypeScript 7 has no compiler API: tools that need it (typescript-eslint, the Nx TypeScript and boundary plugins) do not run here.
- Shared dependency versions live in the `catalog` of `pnpm-workspace.yaml`.
- `apps/web/src/routeTree.gen.ts` is generated by the router plugin.
- Commits follow Conventional Commits; commitlint enforces it in a `commit-msg` hook.
