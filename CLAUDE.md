# learning-curve — notes for coding agents

- Stack: TanStack Start (React 19, file routes in `src/routes`, server routes via `server.handlers`), Vite 8, Nitro, TypeScript strict.
- Source of truth for the schedule: `src/lib/plan/content.ts` + `src/lib/plan/schedule.ts`. `src/data/plan.json` is generated by `pnpm run plan`; never hand-edit it, regenerate.
- After changing content or rules: `pnpm run plan && pnpm run typecheck && pnpm run build`.
- Weekly study budget is 12 h; `pnpm run plan` warns when a week exceeds it. Gym and Saturday buffer do not count.
- Times are Europe/Minsk wall-clock strings; use helpers in `src/lib/plan/dates.ts`, never `new Date(localString)`.
- UI text is Russian; code and docs are English. Event titles: `<Course short name> — <Module / topic>`; descriptions: course URL, module URL, 1–3 line goal.
- `src/routeTree.gen.ts` is generated by the router plugin.
