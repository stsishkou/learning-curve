# @lc/i18n

Interface translations (ru base, en, es) compiled with Paraglide JS, and locale-aware date and hour text.

- `./messages`: `m.key()`, one function per message. `./runtime` and `./server`: the locale and its detection.
- `./format`: date and hour text in the active locale (`src/format.ts`).
- `messages/{ru,en,es}.json`: the source; every string goes into all three. `src/paraglide/` is generated by
  `pnpm run i18n`, never edited.

Imports no workspace package and no `node:*` (Oxlint).

Tested with Vitest (`format`): `pnpm exec nx run @lc/i18n:test`. `pnpm run check:i18n` finds missing and unused keys.

Owns no data files.
